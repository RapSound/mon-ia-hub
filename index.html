💡 Comment ça marche

Cet outil utilise les API publiques de Pollinations — gratuites, sans clé. Chaque code block généré par l'IA peut être téléchargé individuellement, et tu peux exporter tous les fichiers d'une conversation en ZIP.

Le mode Auto (orchestrateur) analyse ta demande, détecte si elle nécessite plusieurs sous-tâches (code + explication, comparaison, traduction + réécriture...) et les exécute en parallèle sur les meilleurs modèles.

⚠️ Si tu ouvres ce fichier en file://, certains navigateurs peuvent bloquer les requêtes réseau. Utilise un petit serveur local (python -m http.server) pour une fiabilité maximale.
