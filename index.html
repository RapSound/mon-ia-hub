💡 Comment fonctionne l'orchestrateur ?

1. Ton prompt est envoyé à un planificateur qui analyse l'intention.

2. Il produit un plan JSON listant des sous-tâches (texte image vidéo code).

3. Les sous-tâches s'exécutent en parallèle sur les meilleurs modèles pour chaque type.

4. Un synthétiseur combine tous les résultats en une réponse finale cohérente.
